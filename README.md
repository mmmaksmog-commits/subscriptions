# 🔁 Подписки

**Сколько уходит на подписки в месяц и в год, календарь списаний и подсказки, где сэкономить.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/subscriptions/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- Месячная и годовая сумма, диаграмма по категориям
- Календарь ближайших списаний
- Автоматический перенос даты на следующий период
- Подсказки: что не используется, годовые тарифы, дубли
- Данные хранятся только в браузере

## Стек

JavaScript, SVG. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/subscriptions.git
cd subscriptions
python3 -m http.server 8000
```
